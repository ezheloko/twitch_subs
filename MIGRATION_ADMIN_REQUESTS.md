# Миграция: Система заявок на администрирование

## Что изменилось:

1. Добавлена модель `AdminRequest` в Prisma schema
2. Изменена логика добавления администраторов - теперь через систему заявок
3. Главный администратор не может быть перезаписан при логине через Twitch
4. Добавлена возможность передачи прав главного администратора

## Шаги для применения изменений:

### 1. На сервере примените миграцию базы данных:

```bash
cd /root/twitch-subscribers
npm run db:push
```

Или через миграцию:

```bash
npm run db:migrate
```

### 2. Пересоберите проект:

```bash
npm run build
pm2 restart all
```

### 3. Мигрируйте существующих админов (если есть):

Если у вас уже есть администраторы, созданные старым способом (с `twitchLogin`), 
нужно создать для них одобренные заявки:

```bash
node scripts/migrate-existing-admins.js
```

Это создаст одобренные заявки для всех пользователей с `twitchLogin`, 
чтобы они не потеряли доступ к админ-панели.

### 4. Проверьте работу:

1. Войдите как главный администратор
2. Перейдите в "Настройки" → "Заявки на администрирование"
3. Другой пользователь должен залогиниться через Twitch и отправить заявку
4. Главный администратор может одобрить или отклонить заявку

## Важные изменения:

- **Главный администратор защищен**: При логине через Twitch статус `isMainAdmin` не перезаписывается
- **Система заявок**: Пользователи отправляют заявки, главный админ их рассматривает
- **Передача прав**: Главный админ может передать свои права любому другому админу
- **Удаление админа**: Удаляется заявка, а не пользователь (пользователь остается, но теряет права)

## Откат (если нужно):

Если нужно откатить изменения, удалите модель `AdminRequest` из `prisma/schema.prisma` и выполните:

```bash
npm run db:push
```
