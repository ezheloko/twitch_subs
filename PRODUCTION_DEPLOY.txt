## 🖥️ Требования

- VPS сервер с Ubuntu 20.04+ или Debian 11+
- Минимум 2GB RAM, 20GB диска
- Root доступ к серверу
- Доменное имя (опционально, но рекомендуется)
- Twitch Developer Account

## 📦 Установка зависимостей системы

### Шаг 1: Установка Node.js 20.x

```bash
# Установка Node.js через NodeSource
curl -fsSL https://deb.nodesource.com/setup_20.x | bash -
apt install -y nodejs

# Проверка версии

```

### Шаг 2: Установка PostgreSQL

```bash
# Установка PostgreSQL
apt install -y postgresql postgresql-contrib

# Запуск PostgreSQL
systemctl start postgresql
systemctl enable postgresql

# Проверка статуса
systemctl status postgresql
```

### Шаг 3: Установка Nginx

```bash
# Установка Nginx
apt install -y nginx

# Запуск Nginx
systemctl start nginx
systemctl enable nginx

# Проверка статуса

```

# Настройка автозапуска PM2

## 🗄️ Настройка базы данных PostgreSQL

### Шаг 1: Создание базы данных и пользователя

```bash
# Переключение на пользователя postgres
sudo -u postgres psql

# В консоли PostgreSQL выполните:
CREATE DATABASE twitch_subscribers;
CREATE USER twitch_user WITH PASSWORD 'ваш-надежный-пароль';
GRANT ALL PRIVILEGES ON DATABASE twitch_subscribers TO twitch_user;
ALTER USER twitch_user CREATEDB;
\q
```

**Важно:** Замените `'ваш-надежный-пароль'` на надежный пароль (минимум 16 символов, буквы, цифры, символы).

### Шаг 2: Проверка подключения

```bash
# Проверка подключения
sudo -u postgres psql -d twitch_subscribers -c "SELECT version();"
```

## ⚙️ Настройка переменных окружения

### Шаг 1: Создание файла .env

```bash
cd /root/twitch_subs
cp .env.example .env  # Если есть пример файла
# или
nano .env  # Создать новый файл
```

### Шаг 2: Заполнение переменных окружения

Откройте файл `.env` и заполните следующие переменные:

```env
# База данных PostgreSQL
DATABASE_URL="postgresql://twitch_user:ваш-надежный-пароль@localhost:5432/twitch_subscribers?schema=public"

# NextAuth.js
NEXTAUTH_URL="https://ваш-домен.com"
NEXTAUTH_SECRET="сгенерируйте-случайную-строку-минимум-32-символа"

# Twitch OAuth (получите на https://dev.twitch.tv/console/apps)
TWITCH_CLIENT_ID="ваш-twitch-client-id"
TWITCH_CLIENT_SECRET="ваш-twitch-client-secret"

# Node.js окружение
NODE_ENV="production"
```

**Как получить NEXTAUTH_SECRET:**
```bash
openssl rand -base64 32
```

**Как получить Twitch OAuth credentials:**
1. Перейдите на https://dev.twitch.tv/console/apps
2. Нажмите "Register Your Application"
3. Заполните:
   - Name: любое имя (например, "Twitch Subs")
   - OAuth Redirect URLs: `https://ваш-домен.com/api/auth/callback/twitch`
   - Category: Website Integration
4. Нажмите "Create"
5. Скопируйте Client ID и создайте Client Secret

### Шаг 3: Сохранение файла

В nano: `Ctrl+O` (сохранить), `Enter`, `Ctrl+X` (выйти)

## 🔐 Настройка Twitch OAuth

### Шаг 1: Регистрация приложения на Twitch

1. Перейдите на https://dev.twitch.tv/console/apps
2. Войдите в свой Twitch аккаунт
3. Нажмите "Register Your Application"
4. Заполните форму:
   - **Name:** Twitch Subscribers (или любое другое имя)
   - **OAuth Redirect URLs:** 
     - Для разработки: `http://localhost:3000/api/auth/callback/twitch`
     - Для продакшн: `https://ваш-домен.com/api/auth/callback/twitch`
   - **Category:** Website Integration
5. Нажмите "Create"
6. Скопируйте **Client ID**
7. Нажмите "New Secret" и скопируйте **Client Secret**

### Шаг 2: Добавление credentials в .env

Добавьте полученные значения в файл `.env`:
```env
TWITCH_CLIENT_ID="ваш-client-id"
TWITCH_CLIENT_SECRET="ваш-client-secret"
```

## 🌐 Настройка Nginx

### Шаг 1: Создание конфигурации Nginx

```bash
nano /etc/nginx/sites-available/twitch-subs
```

### Шаг 2: Добавление конфигурации

Вставьте следующую конфигурацию (замените `ваш-домен.com` на ваш домен или IP):

```nginx
server {
    listen 80;
    server_name ваш-домен.com;

    # Максимальный размер загружаемых файлов (50MB)
    client_max_body_size 50M;

    # Проксирование на Next.js приложение
    location / {
        proxy_pass http://localhost:3000;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_cache_bypass $http_upgrade;
    }

    # Статические файлы (загрузки)
    location /uploads/ {
        alias /root/twitch_subs/public/uploads/;
        expires 30d;
        add_header Cache-Control "public, immutable";
    }

    # Favicon и другие статические файлы
    location ~* \.(jpg|jpeg|png|gif|ico|css|js|svg|woff|woff2|ttf|eot)$ {
        proxy_pass http://localhost:3000;
        expires 30d;
        add_header Cache-Control "public, immutable";
    }
}
```

### Шаг 3: Сохранение и активация конфигурации

```bash
# Создание символической ссылки
ln -s /etc/nginx/sites-available/twitch-subs /etc/nginx/sites-enabled/

# Удаление дефолтной конфигурации (если нужно)
rm /etc/nginx/sites-enabled/default

# Проверка конфигурации
nginx -t

# Перезагрузка Nginx
systemctl reload nginx
```

### Шаг 4: Создание директории для загрузок

```bash
mkdir -p /root/twitch_subs/public/uploads/{background,item,avatar}
chmod -R 755 /root/twitch_subs/public/uploads
```

## 🔒 Настройка SSL (Let's Encrypt)

**Важно:** SSL работает только с доменным именем, не с IP-адресом.

### Шаг 1: Получение SSL сертификата

```bash
certbot --nginx -d ваш-домен.com
```

Следуйте инструкциям:
- Введите email для уведомлений
- Согласитесь с условиями (A)
- Выберите, перенаправлять ли HTTP на HTTPS (рекомендуется: 2)

### Шаг 2: Автоматическое обновление сертификата

```bash
# Проверка автоматического обновления
certbot renew --dry-run
```

Certbot автоматически настроит обновление через cron.

### Шаг 3: Обновление NEXTAUTH_URL в .env

После получения SSL обновите `.env`:
```env
NEXTAUTH_URL="https://ваш-домен.com"
```

И перезапустите приложение (см. раздел "Запуск через PM2").

## 👤 Создание главного администратора

### Шаг 1: Первый вход через Twitch

1. Откройте в браузере: `https://ваш-домен.com/admin`
2. Войдите через Twitch
3. Первый пользователь автоматически станет главным администратором

### Шаг 2: Проверка статуса в базе данных

```bash
sudo -u postgres psql -d twitch_subscribers -c "SELECT email, \"twitchLogin\", \"isMainAdmin\" FROM \"User\";"
```

Должен быть виден ваш пользователь с `isMainAdmin: true`.

### Шаг 3: Если нужно установить главного админа вручную

```bash
cd /root/twitch_subs
node scripts/fix-admin-direct.js
```

Или через SQL:
```bash
sudo -u postgres psql -d twitch_subscribers
```

```sql
UPDATE "User" 
SET "isMainAdmin" = true 
WHERE LOWER(email) = LOWER('ваш-email@example.com');
```

## 🐛 Решение проблем

### Проблема: Приложение не запускается

**Решение:**
```bash
# Проверьте логи
pm2 logs twitch-subs --err

# Проверьте, что порт 3000 свободен
netstat -tulpn | grep 3000

# Проверьте переменные окружения
cd /root/twitch_subs
cat .env

# Попробуйте запустить вручную для отладки
npm start
```

### Проблема: Ошибка подключения к базе данных

**Решение:**
```bash
# Проверьте, что PostgreSQL запущен
systemctl status postgresql

# Проверьте подключение
sudo -u postgres psql -d twitch_subscribers -c "SELECT 1;"

# Проверьте DATABASE_URL в .env
cat .env | grep DATABASE_URL
```

### Проблема: 502 Bad Gateway

**Решение:**
```bash
# Проверьте, что приложение запущено
pm2 status

# Проверьте логи приложения
pm2 logs twitch-subs

# Проверьте логи Nginx
tail -f /var/log/nginx/error.log

# Проверьте конфигурацию Nginx
nginx -t
```

### Проблема: Файлы не загружаются (403 Forbidden)

**Решение:**
```bash
# Проверьте права доступа
ls -la /root/twitch_subs/public/uploads

# Установите правильные права
chmod -R 755 /root/twitch_subs/public/uploads
chown -R root:root /root/twitch_subs/public/uploads
```

### Проблема: Ошибка аутентификации Twitch

**Решение:**
1. Проверьте `TWITCH_CLIENT_ID` и `TWITCH_CLIENT_SECRET` в `.env`
2. Проверьте Redirect URL в настройках Twitch приложения:
   - Должен быть: `https://ваш-домен.com/api/auth/callback/twitch`
3. Проверьте `NEXTAUTH_URL` в `.env`:
   - Должен быть: `https://ваш-домен.com`
4. Перезапустите приложение:
```bash
pm2 restart twitch-subs
```

### Проблема: Недостаточно памяти при сборке

**Решение:**
```bash
# Увеличьте swap
fallocate -l 2G /swapfile
chmod 600 /swapfile
mkswap /swapfile
swapon /swapfile
echo '/swapfile none swap sw 0 0' >> /etc/fstab

# Или увеличьте лимит памяти Node.js
export NODE_OPTIONS="--max-old-space-size=2048"
npm run build
```

### Проблема: Модальные окна перекрываются аватарами

**Решение:**
Это уже исправлено в коде. Убедитесь, что используете последнюю версию:
```bash
git pull origin main
npm run build
pm2 restart twitch-subs
```
